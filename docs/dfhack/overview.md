# DFHack overview

[DFHack](https://docs.dfhack.org/en/stable/) is a community-maintained add-on that exposes Dwarf Fortress engine internals as scripts and plugins. It ships with hundreds of tools — some are quality-of-life, some are cheats, most are somewhere in between.

## Philosophy used on this site

- DFHack tools are documented in this section or in `=== "DFHack"` tabs alongside vanilla procedures.
- We link the **stable** docs (`docs.dfhack.org/en/stable/`), not master.
- Tools that materially change the game (e.g. revealing the map, removing aquifers) are flagged as such.

## Getting started

1. Install DFHack matching your DF version — see [DFHack installation](https://docs.dfhack.org/en/stable/docs/Installing.html).
2. Launch DF; DFHack opens a console window.
3. Type `help` for a list of commands, `tags` to browse categories.
